# moomoo_paper_trading.py — What It Does and How to Run It

## What This Script Does (Plain English)

`moomoo_paper_trading.py` is the **execution layer** for paper trading. It reads the signals generated by `predict.py` and submits them as orders in Moomoo's simulated (paper) trading environment.

Paper trading = real market prices, fake money. It lets you test the full pipeline in live conditions before risking real capital.

**Safety controls built in:**
- Only trades the 4 approved tickers (AMZN, MSFT, TSLA, GOOGL) by default
- Short selling is disabled by default
- Optional interactive confirmation before each trade
- Logs every order to `signals/paper_trades.csv`

---

## How to Run It

```bash
# Submit paper trades for all approved tickers with actionable signals
python moomoo_paper_trading.py

# Only trade specific tickers
python moomoo_paper_trading.py --include AAPL MSFT

# Exclude certain tickers
python moomoo_paper_trading.py --exclude TSLA

# Ask for confirmation before each trade (recommended while learning)
python moomoo_paper_trading.py --confirm

# Override: allow shorts (not recommended for beginners)
python moomoo_paper_trading.py --allow-shorts
```

## Setup Requirements

1. **Moomoo account**: Create at https://www.moomoo.com
2. **Paper trading enabled**: In the Moomoo app, switch to the paper trading account
3. **MooMoo OpenD**: A local gateway process that must be running before this script executes. Download from https://www.moomoo.com/openapi/
4. **Moomoo API installed**: `pip install moomoo_api` (already in requirements.txt)

---

## Key Concepts

| Term | Plain-English Meaning |
|---|---|
| **Paper trading** | Simulated trading with fake money but real market prices. No financial risk. |
| **Approved universe** | The list of stocks allowed in live/paper trading, stored in `approved_live_tickers.csv`. Separate from the training universe to limit risk. |
| **Actionable signal** | A signal from `predict.py` with `actionable = True`. Means confidence ≥ threshold AND direction is LONG (or LONG + SHORT if allowed). |
| **OpenD** | Moomoo's local server process. The Python API sends orders to OpenD, which forwards them to Moomoo's servers. |
| **Include/exclude filters** | Command-line flags to manually restrict or skip certain tickers for one run. |
| **Short selling** | Betting that a stock will go down by borrowing and selling shares you don't own. Disabled by default — complex and risky. |

## Output Files

| File | Contents |

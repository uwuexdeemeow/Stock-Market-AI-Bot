Diagnosis
long_short: −16.14%, Sharpe −0.43, NW −1.68. 29 trades, all SHORTS, 10% win rate. Lost $1614.
long_only: +8.21%, Sharpe 0.19, NW 0.63. 54 trades. 2022 alpha +26.91% vs SPY (works in bear, dilutes in bull).
NVDA train summary: ALL 4260 predictions land in 65-70 bucket. Threshold sweep precision = 0.6723 at every cutoff 52.5→65.0. Coverage = 1.0 everywhere.

This show three rotten things at root:

Root cause 1 — Triple-barrier label badly imbalanced
baseline_up_rate = 32.77% means only 1/3 of bars hit +2×ATR before −1×ATR or time-out. Model "67% accuracy" is majority-class shortcut (just predict DOWN almost always). Asymmetric barriers (+2 up / −1 down) make UP class rare. Probabilities collapse.

Root cause 2 — Calibrator dead
Every single test row lands in 65-70 bucket. Threshold sweep flat at 0.6723 across the board. Calibrator has zero rank-ordering power. The Brier-gate in confidence_calibration.py does not reject constant-output calibrators.

Root cause 3 — Shorts in a bull market with broken vote
With probability collapse, almost no ticker triggers direction_vote == "SHORT". The ranking falls back to bottom-by-expected-return. NVDA was the best stock of the decade — model shorted it 7 times, lost every one. Long_short bucket is pure poison.

Fix plan, ordered by leverage
Tier 1 — kill the bleeding now (each: minutes to apply)
1. Disable shorts. Set LIVE_SHORTS_ENABLED = False, run --mode long_only. You skip the −$1614 short slippage. Long_only Sharpe alone is 0.19, not great but no longer disaster. Single biggest one-line win.

2. Bump CROSS_SECTIONAL_TOP_N from 1 → 3. Only 54 long trades in 12 years is statistically dead. Top-3 gives ~150 trades, t-stat power jumps √3≈1.7×. Ballpark: NW from 0.63 → ~1.1.

3. Fix the triple-barrier asymmetry. In labels.py, change barriers to symmetric +1.5*ATR / −1.5*ATR. Should pull baseline_up_rate from 32% to ~45-50%. Class becomes learnable instead of shortcut.

4. Add scale_pos_weight to XGB. In build_models():

n_pos = int(y_dir_train.sum()); n_neg = len(y_dir_train) - n_pos
common["scale_pos_weight"] = n_neg / max(n_pos, 1)
Forces model to weight rare class. Will produce real probability spread instead of all-65%.

Tier 2 — fix the calibrator (1-2 hours each)
5. Reject constant-output calibrators. In confidence_calibration.fit_direction_calibrator, after isotonic fit add:

if (p_val_cal.max() - p_val_cal.min()) < 0.05:
    return None  # rank-power dead, fall through to Platt
Currently the Brier-only gate accepts a constant output if it happens to beat raw Brier on a single split.

6. Drop signal_quality bucketing entirely; use rank directly. Buckets are noise when probability collapsed. In apply_cross_sectional_ranking, you already rank by expected_return — just delete assign_signal_quality from the pipeline. The user added BACKTEST_ALLOWED_SIGNAL_QUALITIES as workaround; remove it and remove the gate.

7. Trend veto on shorts. Even if you re-enable shorts later, hard rule: if ticker.close > ticker.ma_200, no SHORT signal regardless of model output. NVDA wreck would have been blocked.

Tier 3 — strategy structure (1-2 days each)
8. Hybrid SPY-base + signal overlay. Current strategy holds cash 70% of the time → drags Sharpe in bull years. Set base allocation = 50% SPY, then top-up with the cross-sectional signals. 2022 alpha stays (model + half-SPY-down beats full SPY); bull years stop bleeding cash drag.

9. ATR-based position sizing. Replace BASE_POSITION_SIZE_PCT = 0.15 with risk-budget: shares = (0.01 * capital) / (1.5 * ATR_20d). Caps single-trade loss at ~1% of equity. Loss tickers (MU −$255 avg, AMD −$63 avg) currently dominate winners (META +$66, MSFT +$56) because position sizing is unit-equal not risk-equal.

10. Volatility-adjusted target. Switch PREDICTION_TARGET from "triple_barrier" back to "vol_adjusted". Triple-barrier on ATR is fundamentally noisy on a 10-day horizon. Vol-adjusted excess return is smoother and more learnable when the model only has 1990 effective rows.
